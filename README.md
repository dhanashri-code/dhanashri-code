# 🚀 Featured Project

## 🏏 Virat Kohli Performance Dashboard | Power BI & DAX

An interactive **Power BI analytics dashboard** designed to analyze Virat Kohli's batting performance across **formats, years, milestones, and career phases**.

### 🛠️ Tools & Technologies

`Power BI` `DAX` `Power Query` `Excel` `Data Visualization`

### 📌 Dashboard Pages

**01 — Overview**

Provides a high-level summary of career performance, including:

* Total Runs
* Batting Average
* Strike Rate
* Highest Score
* Centuries
* Half-Centuries

**02 — Performance Analysis**

Analyzes:

* Runs
* Batting Average
* Strike Rate
* Highest Score
* Dot-Ball Percentage
* Career Phases
* Performance across formats and years

**03 — Milestones & Batting Analysis**

Explores:

* 50s and 100s
* Boundaries
* Conversion Rate
* Fours
* Sixes
* Balls Faced
* Dismissals

**04 — Details**

Provides year-level **drill-through analysis** with format-wise performance and milestone breakdowns.

### 💡 What This Project Demonstrates

* Building interactive Power BI dashboards
* Creating analytical DAX measures
* Data transformation using Power Query
* KPI development

* Performance trend analysis
